### Task 1: Data Preprocessing & EDA (Titanic Dataset)

**Objective:** Perform Exploratory Data Analysis on Titanic dataset to understand survival patterns.

**Dataset:** Titanic dataset from Kaggle

**Work Done:**

- EDA: survival count, survival by gender (female 74% vs male 18%), by Pclass, age distribution, fare analysis
- Visualizations using Seaborn and Matplotlib

**File:** Task1_EDA_Titanic.ipynb
