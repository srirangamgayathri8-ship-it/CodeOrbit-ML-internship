## Task 1: Titanic EDA - Exploratory Data Analysis

**Objective:** Perform Exploratory Data Analysis on Titanic dataset to understand survival patterns.

**Dataset:** Titanic dataset from Kaggle

**Work Done:**
- Data cleaning and handling missing values
- Univariate and Bivariate analysis
- Survival rate by Gender, Age, Pclass, Fare
- Data visualization using Matplotlib & Seaborn
- Feature insights for model building

**Tools Used:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

**File:** `Task1_EDA_Titanic.ipynb`

## How to Run
1. Clone the repo
2. Open notebook in Jupyter/Colab
3. Run all cells
